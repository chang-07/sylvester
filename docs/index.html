The rest of the popover

It cannot move your money

Not a policy — the shape of the connection.

Read-only

OAuth2 with PKCE, scoped to read. The token can't place trades or move money.

No Sylvester server

Your Mac talks to the API directly — sign-in included.

Keychain only

Tokens never touch disk in plaintext, and never go anywhere else.

No analytics

No crash reporting, no usage pings, no accounts.

Don't take any of it on trust — read the source.

Install

Requires macOS 14 (Sonoma) or later on Apple Silicon, and a free SnapTrade account.

Install it. Via Homebrew, or grab the .dmg from Releases and drag it to Applications. 
brew install --cask chang-07/tap/sylvester
Clear the quarantine flag. Sylvester is ad-hoc signed rather than notarized, so macOS blocks it once on first open. 
xattr -dr com.apple.quarantine /Applications/Sylvester.app
Sign in. Click the menubar icon; your browser opens to approve read access.
Link a brokerage. The connection portal opens; your accounts appear once it lands.
